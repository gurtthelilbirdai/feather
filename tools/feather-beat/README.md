# Feather Beat

A rhythm game for small birds. Notes fall down four lanes and you hit them with
**D F J K** (or the arrow keys) exactly as the beat plays.

- Two songs, pick either one from the dropdown
- Real timing windows: perfect / good / miss
- Combo, score, accuracy, health bar, lives
- 28-note chart from "Feather Beat One", 43-note chart from "Feather Beat Two"
- Separate shared leaderboards per track (SQLite behind the API, ntfy fallback on the public copy)
- Saves your best score locally

Run it locally: open `index.html` through the site server (port 8485) so the
audio and API work.
